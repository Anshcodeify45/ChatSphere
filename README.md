📌 Overview

ChatSphere 💬 is a full-stack real-time chat application built using the MERN stack. It allows users to send and receive messages instantly with a smooth and modern interface.
The app uses WebSockets to provide real-time communication, along with features like typing indicators and online status tracking to enhance user experience.

🚀 Live Demo
👉 https://chat-sphere-iota-sepia.vercel.app/login

✨ Features
⚡ Real-time messaging using Socket.IO
👀 Typing indicator (live user activity)
🟢 Online / Offline user status
🔄 Auto-scroll chat interface
💾 Persistent message storage (MongoDB)
🔐 User authentication system
🎨 Clean, modern UI
🛠️ Tech Stack

Frontend

Backend

⚙️ Installation & Setup
🔹 1. Clone the Repository
git clone https://github.com/your-username/chatsphere.git
cd chatsphere
🔹 2. Setup Backend
cd backend
npm install

Run backend:
npm start

🔹 3. Setup Frontend
cd frontend
npm install

Run frontend:
npm start
